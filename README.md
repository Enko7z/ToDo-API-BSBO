ToDo API (Матрица Эйзенхауэра)

Описание

REST API для управления персональными задачами с интеллектуальной классификацией по Матрице Эйзенхауэра.
Система автоматически определяет срочность задачи на основе дедлайна и рассчитывает, в какой квадрант времени она попадает — помогая сфокусироваться на действительно важном.

Возможности

Создание задач с указанием дедлайна
Автоматический расчёт срочности (is_urgent) на основе дедлайна:
    Срочно — если до дедлайна ≤ 3 дней
    Не срочно — если дедлайн позже или не указан
Автоматическое определение квадранта (Q1–Q4)
Расширенная статистика:
Общая по квадрантам и статусам
По соблюдению сроков (в срок / с опозданием / просрочено)
Фоновое обновление срочности ежедневно в 9:00 UTC (с возможностью тестирования каждые 5 минут)
Эндпоинт для получения задач, срок которых истекает сегодня

Технологии

Python 3.11
FastAPI 0.119 (асинхронный, с автоматической документацией)
SQLAlchemy 2.0 + PostgreSQL (через Supabase)
Pydantic v2 — строгая валидация данных
APScheduler — фоновое планирование задач

Запуск локально
1. Клонируйте репозиторий и перейдите в папку проекта:
git clone https://github.com/Enko7z/ToDo-API-BSBO.git
cd todo-api-eisenhower
2. Создайте и активируйте виртуальное окружение:
python -m venv venv
source venv/bin/activate      # Linux/macOS
venv\Scripts\activate         # Windows
3. Установите зависимости:
pip install -r requirements.txt
4. Настройте подключение к Supabase (в файле database.py или через .env).
5. Запустите сервер:
uvicorn main:app --reload
6. Откройте документацию:
http://localhost:8000/docs

Основные эндпоинты
Задачи:
POST /api/v2/tasks — создать задачу (указываем deadline_at, не is_urgent)
GET /api/v2/tasks — получить все задачи
GET /api/v2/tasks/{id} — получить задачу с полями days_until_deadline и status_message
GET /api/v2/tasks/today — задачи, дедлайн которых сегодня
PATCH /api/v2/tasks/{id}/complete — отметить как выполненную

Статистика:
GET /api/v2/stats/ — общая статистика (всего, по квадрантам, по статусам)
GET /api/v2/stats/timing — статистика по срокам выполнения

Пример запроса
{
  "title": "Подготовить презентацию",
  "description": "Для встречи с инвесторами",
  "is_important": true,
  "deadline_at": "2025-12-15T10:00:00Z"
}
